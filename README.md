# Breakout
Breakout 2D using OpenGL

Creating using resources at learnopengl.com

## Requirements

**Font Rendering**
[FreeType](https://www.freetype.org/) // Freetype header folder & ft2build.h should be placed in your solution directory

**OpenGL Maths Library**
[glm](https://glm.g-truc.net/0.9.9/index.html)

**Sound**
[irrKlang](https://www.ambiera.com/irrklang/)

**Image Loader**
[SOIL2](https://bitbucket.org/SpartanJ/soil2/src/default/)

**OpenGL**

[GLFW](https://www.glfw.org/)

[GLEW](http://glew.sourceforge.net/) / [GLAD](https://glad.dav1d.de/)


### Controls

**Menu**

W & S - Select Level

SPACE - Start Level

**Game**

A - Move paddle left

D - Move paddle right

SPACE - Launch ball
